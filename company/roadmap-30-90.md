# 30/90-day roadmap

## First 30 days

1. Audit 3–5 workflows for repetition, rights, observation cutoff, typed action, outcome, safe transition, and holdout feasibility.
2. Freeze one task only if at least 20 defensible episodes are plausible.
3. Build compiler v0: provenance plane → task package → replay/rule backend → typed trace → grader vector.
4. Compare human, generic model, retrieval, and rules/optimization baselines with blind grading and leakage tests.
5. Separate operational, evaluation, training, derivative, export, retention, and revocation grants in the rights contract.
6. Run synthetic/replay work until rights approval; then collect at least 20 shadow episodes with no autonomous outbound action.
7. Ask prospective buyers for workflow, tools, grader, rights, acceptance, and budget-owner specifications.

## Days 31–90

1. Freeze the environment prospectively and evaluate new episodes.
2. Test one transfer axis and build a second task adapter using the same contracts.
3. Measure live-rank correlation, uncertainty calibration, coverage, and exploitation.
4. Measure environment 1→2 marginal build time, full cost, and reusable contract share.
5. Open an external eval/training-usefulness test only after utility and transfer pass.

## Stop rules

- Fewer than 20 defensible episodes: redirect the task.
- Simple baseline tie or unstable ranking: stop the foundry claim and repair the grader/task.
- Ambiguous rights: fail closed.
- No written buyer specification or paid pilot after the discovery window: hold the frontier-lab supplier thesis.
- No incremental lift over generic model + private context + retrieval + harness: stop company-specific weights/RL investment.
