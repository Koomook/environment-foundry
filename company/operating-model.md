# Operating model

## What we make

The unit of production is not a pile of company documents. It is a rights-valid environment package with an observation cutoff, typed actions, transition semantics, termination, grader vector, uncertainty, reset/replay, and provenance.

## How work flows

```text
Buyer or internal task specification
→ workflow audit and rights map
→ field reconstruction by an FDE
→ task/transition/grader design by a researcher
→ baseline and leakage tests
→ rights-valid shadow episodes
→ held-out transfer and prospective outcome checks
→ buyer acceptance or stop decision
```

## Roles

- Founder / Company Council: priority, budget, external commitments, stop/continue.
- FDE: maps real workflow objects, sources, omissions, and uncertainty without inventing causality.
- Researcher / Eval engineer: freezes task contracts, graders, holdouts, leakage and exploitation tests.
- Environment engineer: implements replay/reset/step interfaces and reproducible traces.
- Rights steward: defines allowed observation, action, training, derivative use, retention, and revocation.
- Commercial lead: collects written specifications and acceptance tests rather than vague interest.
- Memory Compiler: promotes only evidence-backed atomic claims to the canonical wiki.

## First operating constraint

The company may help a partner use the resulting environment, but it does not promise full-company AX. Customer transformation is a possible benefit, not the delivery obligation.
