# Company functions

Each function owns a class of outputs, not an independent strategy.

| Function | Output |
|---|---|
| `01-research-and-evals` | task ontology, graders, baselines, holdouts, research claims |
| `02-environment-engineering` | compiler, replay/reset/step interfaces, reproducible traces |
| `03-field-operations` | workflow maps, source/provenance reconstruction, shadow trials |
| `04-rights-and-governance` | grants, receipts, action permissions, revocation/deletion controls |
| `05-commercial` | buyer-written specifications, acceptance tests, paid design partners |
| `06-talent` | FDE/researcher selection, calibration, performance evidence |
| `07-corporate` | finance, legal, security, capacity, board/decision operations |
| `08-media` | evidence-labeled narratives; no unsupported public claims |

Current priorities are routed in `knowledge/workstreams/registry.md`.
