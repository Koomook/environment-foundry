# 기업은 모델이 아니라 학습 루프를 소유한다

Applied Compute가 1억 6,000만 달러를 모아 만드는 것은 또 하나의 foundation model이 아닙니다. 기업의 workflow, grader, context, production feedback을 특정 회사가 소유하는 모델에 계속 넣는 공장입니다.

1. Specific Intelligence는 공식 설명상 weights와 runtime context에 존재하고, 실제 system에서는 harness + eval + feedback까지 결합됩니다.
2. 기업 데이터의 핵심은 문서보다 좋은 일을 판별하는 기준입니다.
3. Applied Compute는 AC2와 forward-deployed research를 묶은 model factory입니다.
4. DoorDash 30%, Cognition 10배는 각 고객 harness의 회사 보고 수치입니다.
5. Deploy once, learn forever는 현재 기능이 아니라 roadmap입니다.

Harvey Tenet core는 Harvey와 Fireworks가 훈련했습니다. Applied Compute는 별도 Review Table model을 Harvey와 공동 post-train했습니다. Satya Nadella와의 공식 대담은 이 범주가 큰 의제가 됐다는 신호이지만 Microsoft 투자나 독점 제휴를 뜻하지 않습니다.

범용 모델 경쟁 다음은 각 회사가 자기 업무의 학습 루프를 얼마나 잘 소유하느냐의 경쟁입니다.
