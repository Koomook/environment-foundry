# Environment Foundry Content Guide

이 디렉터리는 Environment Foundry 소유 콘텐츠의 canonical root다. 상위
`/Users/bong/environment-foundry/AGENTS.md`를 먼저 따르고, canonical knowledge는
`knowledge/wiki`에서만 확정한다. 콘텐츠는 accepted evidence를 번역할 뿐 새로운
회사 진실을 만들지 않는다.

- `units/`: evidence/thesis를 채널과 분리한 canonical content unit
- `campaigns/`: 여러 unit과 channel을 묶는 목표 단위
- `channels/rldr/`: RLDR 배포 adaptation과 정책 포인터
- `receipts/`: 승인·게시 영수증

Feed Attention은 제작 엔진, datafooding은 입력 엔진, RLDR은 배포 채널이다.
원본을 Content Mesh Router나 다른 principal로 복제하지 않는다.
