# Environment Foundry Content

Environment Foundry를 발전시키기 위해 만드는 콘텐츠의 canonical root다.

```text
datafooding (input engine)
  -> knowledge/wiki (accepted evidence)
  -> content/units (canonical thesis)
  -> Feed Attention (production engine)
  -> content/channels/rldr (distribution adaptation)
  -> content/receipts (publication proof)
```

Podcast, Writing, Video는 content unit의 `formats`로 기록한다. LinkedIn, YouTube,
RLDR은 `channels`로 기록한다. 같은 unit을 여러 format으로 만들더라도 원본은
하나만 둔다.

기존 RLDR 제작 저장소와 datafooding 작업 트리는 절대경로·미커밋 작업을
보호하기 위해 현재 위치에 유지하며 `/Users/bong/content` 카탈로그에서 연결한다.
