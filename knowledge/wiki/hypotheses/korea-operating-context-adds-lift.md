# Korea Operating Context Adds Lift

## Claim

Korean operating context provides incremental held-out value that cannot be matched by a generic model with translated private context, retrieval, and the same harness.

## Test

Run a controlled locality ablation only after one task has valid utility and transfer evidence.

## Threshold

The local-context arm must show stable incremental lift on frozen held-out tasks without additional rights or leakage violations.

## Stop rule

If a non-local baseline matches it after equal context and tooling, stop claiming Korea-specific data advantage.
