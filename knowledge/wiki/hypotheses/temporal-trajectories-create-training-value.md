# Temporal Trajectories Create Training Value

## Claim

Decision-time observations, actions, relationships, and delayed outcomes add held-out evaluation or learning value beyond a static document corpus.

## Test

Freeze temporal/entity holdouts and compare human, generic-model, retrieval, rules, and environment-enabled policies without hindsight leakage.

## Threshold

The environment-enabled arm must improve a buyer-relevant or prospective metric with stable independent grading and no hard-failure regression.

## Stop rule

If gains disappear under frozen holdout, formulation sensitivity, or leakage audit, demote the claim and treat trajectories as archival data only.
