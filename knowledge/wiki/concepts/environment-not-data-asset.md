# Environment, Not Data Asset

A data corpus records observations. An environment additionally defines what the agent may observe, which typed actions it may take, how state changes, when an episode ends, how behavior is graded, and how reset or replay works.

The company mission is to build the engine that creates valid environments, not merely to own more records. See [[episode-replay-simulator-boundary]] and [[company-environment-engine]].
