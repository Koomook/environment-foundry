# Wiki write protocol

Before writing, read `SCHEMA.md`, `index.md`, and recent `log.md`; search for duplicates. Preserve a Git-safe source receipt. Draft risky claims in `_candidates/`. Promote only atomic claims that pass provenance, privacy, duplication, contradiction, graph-fit, verification, and freshness checks. Update the typed page, index, and log in one change.

Never copy private client/person/company payload into `raw/`. Use the external private plane and a safe locator.
