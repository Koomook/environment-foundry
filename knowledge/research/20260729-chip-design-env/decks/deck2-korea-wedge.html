권리 이슈 — 계약의 골격

PDK는 못 가져오고,
IP는 고객 것이다

제약 1

파운드리 PDK NDA

PDK는 재배포 불가 → 환경은 PDK-free 추상화 + 파트너 측 실행(enclave) 설계. export는 허가된 필드만: episode ID, 타입화된 행동, 스칼라 채점, 실행시간, 영수증.
제약 2

고객 IP 소유권

디자인하우스의 RTL/GDS는 팹리스(고객) 자산 → 메타데이터 분리 제공 계약이 핵심 조항. 프로젝트 식별 불가 수준의 집계·익명화가 법적 최소선.
첫 미팅 전 산출물

권리 12필드 → 계약 표

회사 rights semantics(access…publication 12필드)를 계약서 표로 번역. 권리는 서류가 아니라 제품 시맨틱 — 모호하면 닫힌다(fail closed).
어떤 데이터셋도 PDK 파생 파라미터를 포함하면 파운드리 승인이 필요하다.

시나리오 분기 — 어느 경로도 정답으로 미리 고르지 않는다

시나리오 A — 디자인하우스 2개사 POC

A세미파이브 + 에이직랜드

bet
프로젝트 메타데이터 밀도 최고, 상장사 거버넌스, "AI 설계 도구 ⇄ 데이터" 대칭 딜 설계 가능. 세미파이브(삼성 SAFE DSP) + 에이직랜드(TSMC VCA)로 양 파운드리 생태계를 동시에 커버.
drop
대기업(삼성/하이닉스) 첫 파트너 가정, 원시 RTL 확보 시도, 한국 칩 코퍼스 대량 수집.
switch-signal
메타데이터가 고객 NDA상 실제로 분리 불가능하다고 판명되거나, 2개사 모두 60일 안에 export 필드 합의에 실패하면 → B(IP 벤더)로 피벗.
worst ending
90일 협상 끝에 법적 최소선(프로젝트 식별 불가 집계)을 넘지 못해 에피소드 0건 — 딜 구조만 남고 환경은 없다.

시나리오 B — IP 벤더 블록 라이선스

B퀄리타스 또는 오픈엣지 1곳

bet
IP 자체가 상품이라 라이선스 계약 구조가 이미 존재 — 데이터 라이선스로 확장하기 가장 쉬운 유형. 블록 단위라 비식별화·권리 분리가 깔끔하고, 비상장(퀄리타스)이라 의사결정이 빠르다. 검증 자동화 도구가 교환 카드.
drop
프로젝트×노드 교차 메타데이터의 폭(디자인하우스 대비 좁음), 시스템 수준 설계 결정 에피소드.
switch-signal
디자인하우스 딜이 권리 단편화로 막히는 순간 즉시 가동. 반대로 블록 단위만으로는 결정 에피소드 다양성이 부족하다고 확인되면 A와 병행 트랙으로 격상.
worst ending
블록 단위 에피소드만 남아 "칩 설계 환경" 주장이 니치 검증 도구로 축소 — 데이터 브로커로 전락.

시나리오 분기

시나리오 C — 팹리스 공동연구

C딥엑스 / 보스반도체

bet
아키텍처 탐색 로그·워크로드-PPA·컴파일러 코디자인 — "칩 한 개를 깊이 최적화하는 에피소드"로 가치 최상. 딥엑스는 NPU 개발자 생태계 사업을 이미 운영(교육/환경 제공 명분), 정부 자금 수혜사라 국책 공동연구 채널이 열린다. 실패한 설계 실험 로그는 경쟁력 노출이 적어 협상 여지.
drop
원시 RTL 공유(가능성 낮음), 단기 대량 에피소드 기대, 지분·투자 연계 딜.
switch-signal
국책 과제 매칭이 60일 안에 잡히지 않거나, 영업비밀 경계가 실패 로그조차 막으면 중단하고 A/B에 집중.
worst ending
공동연구 MOU와 복도자료만 남고 export된 데이터는 0건 — 명분만 남는다.
synthesis §5 · korea-chip-company-map.md §3-2B, §3-307 / 09
시나리오 분기 · 병행 트랙

시나리오 D — 삼성 SAFE "AI 도구 파트너" 진입

D파운드리 생태계 프레임워크 활용

bet
SAFE가 이미 EDA·IP·DSP·클우드·OSAT 파트너를 인증·중재하는 구조 — 파운드리가 생태계 중재자이므로 데이터 파트너십도 SAFE 안에서 협상하는 것이 현실적. 진입 시 PDK 이슈의 구조적 해소와 생태계 전체 노출이라는 장기 유통 채널 확보.
drop
속도 — 90일 계획과 비정합. 중소 파트너와의 직접 딜을 SAFE 진입에 종속시키지 않는다.
switch-signal
A–C 중 하나라도 POC가 서면 그것을 진입 근거(레퍼런스)로 사용해 가동. 인증 절차가 분기를 넘기면 즉시 보류.
worst ending
인증 미로에 6개월을 소모하고 실계약 0 — 스타트업의 유일한 자산인 속도를 태운다.

결정 규칙 · 출처

우선순위는 정해져 있고,
생사는 게이트가 정한다

실행 순서: ① 디자인하우스 2개사 POC → ② IP 벤더 1곳 → ③ 팹리스 공동연구 → ④ SAFE 병행. 단, 공통 리스크 4가지(파운드리 PDK NDA, 고객 IP 소유권, 경쟁사 배타 조항, 미확정 재무 수치)는 어느 경로에서든 실사(due diligence)로 먼저 확인한다. "한국 회사라서 데이터 접근이 쉽다"는 검증되지 않은 지역성 가정일 수 있다 — 이것이 최대 반론이다.
