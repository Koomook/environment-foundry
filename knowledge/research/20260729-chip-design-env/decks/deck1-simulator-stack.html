ChiPBench의 교훈

프록시 보상의 배신

ChiPBench(arXiv 2407.15026)는 placement AI의 중간 프록시(HPWL 등)가 최종 end-to-end PPA(타이밍·전력·면적)와 상관이 약하다는 것을 OpenROAD end-to-end 플로우로 실증했다. AlphaChip 논쟁("False Dawn" 2306.09633 ↔ "That Chip Has Sailed" 2411.10053)의 뿌리도 같다 — 비공개 데이터 + 프록시 보상 조합은 재현성 논쟁에 취약하다.

모든 싼 측정은 거짓말을 한다. 문제는 얼마나인가다.

설계 원칙

싼 툴이 에피소드를 만들고,
비싼 툴이 검증한다

한 계층의 결과를 다음 계층의 입장에서 다시 채점하는 사다리가 환경의 뼈대다. 사다리의 각 단은 PDK를 공유해야 하고, 오픈 PDK가 전체를 묣 료로 지탱한다 — SKY130/GF180(fab 가능) · Nangate45/ASAP7(연구용).

게이트 순서가 곧 환경 설계 계약이다:
컴파일 → 공개 테스트 → 히든 행동 전수 → 돌연변이 감사 → 품질 프록시(노이즈 플로어 명시) → 사다리 상승 → prospective 상관

이 순서 중 하나라도 건드리지 않은 채점/순위는 신뢰 등급을 깎는다.

시나리오 A — 최소 오픈 스택

AIcarus + Yosys 만

bet
RTL repair·합성 계층만으로 가장 빠르고 싸게 prospective 검증 루프를 돌린다. v1·v2가 이미 이 스택 위에서 검증됐고, Days 0–30 공개 골격과 정합. 초~분 보상 비용으로 에피소드 대량 반복.
drop
물리설계·아키텍처 계층 전체, end-to-end PPA 신호, 라우팅 상관(v2-3의 NOT YET을 미해소로 둠).
switch-signal
파트너가 "합성 이후(라우팅·타이밍) 신호 없이는 못 산다"고 하거나, iter-3 급 프록시 왜곡이 구매자 채점 기준과 충돌하면 → B(풀 사다리)로 상승.
worst ending
싼 환경만 남아 ChiPBench가 경고한 프록시-단독 벤치마크를 재현하고, prospective 상관 게이트에서 탈락.

시나리오 B — 풀 사다리

BIcarus/Verilator + Yosys + OpenROAD + Timeloop

bet
오픈소스 4종으로 사다리 전 구간을 묣 료로 커버. 이번 분기 단일 베팅(reference-design signoff closure 환경)의 뼈대이며, ORFS final-route 채점으로 v2-3의 NOT YET을 해소한다.
drop
SPICE급 충실도, 상용 노드 PDK 정합성, gem5급 아키텍처 DSE(후순위로 미룸).
switch-signal
ORFS 소형 디자인 2개의 final-route 채점이 Days 15–30 안에 안 서거나 구축·운영 비용이 에피소드 생산을 잡아먹으면 → A로 후퇴. 반대로 prospective 상관이 보이고 물리설계 보상이 병목이면 → C(GPU 가속)를 얹음.
worst ending
사다리는 완성했으나 에피소드 시드(파트너 데이터)가 없어 빈 사다리가 된다 — 엔진은 있는데 컴파일할 운영 사건이 없음.

시나리오 C — GPU 가속 중심

CDREAMPlace / AutoDMP 류

bet
DREAMPlace는 CPU 대비 ~30배 가속(논문 주장), AutoDMP는 GPU 1대로 수백 후보를 병렬 평가해 상용 툴·Nature RL 대비 동급 PPA 보고. 대형 디자인에서 물리설계 계층의 보상 1회 비용을 분 단위로 끌어내린다.
drop
RTL·검증 계층, 학습된 정책의 이전(transfer) — BO 중심이라 디자인 간 재사용이 약함. RL 정책 학습 자체는 포기.
switch-signal
파트너 에피소드가 실제 수십만 셀급 물리설계 결정이고, OpenROAD CPU 실행 시간이 보상 예산을 초과한다고 측정될 때.
worst ending
GPU 인프라와 튜닝에 90일을 태우고 환경 계약(돌연변이 감사·노이즈 플로어)은 미검증으로 남는다 — 엔진 없는 placement 연구.

결정 규칙 · 출처

게이트가 고른다,
우리가 아니라

세 시나리오는 배타적이지 않다. A로 시작해 파트너의 채점 요구가 사다리 상승을 요구하면 B로, 물리설계 보상 비용이 병목이면 C를 얹는다. 공통 조건: 어떤 스택이든 히든 채점기 돌연변이 감사와 노이즈 플로어 명시 없이는 순위를 발행하지 않는다.
