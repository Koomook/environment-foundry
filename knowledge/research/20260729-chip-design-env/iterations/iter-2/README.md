# Iteration 2 — 채점기 감사 (뮤테이션 테스트)

- 날짜: 2026-07-29 · 상태: `OBSERVED`
- 산출물: `mutants/gen_mutants.py` → `mutants/generated/`
- 원시 결과: `results/iteration-2.json`

## 가설

채점기는 감사될 때만 신뢰할 수 있다: gold 설계에 대한 **행동 변경 단일 지점
돌연변이는 히든 채점기가 100% 격리(kill)**해야 한다. 생존자가 있으면 그것이
채점기의 사각지대다.

## 만든 것

`seq_gold.v`에 대한 결정론적 돌연변이 8개 (정확한 문자열 치환, 불일치 시 생성 실패):

| 돌연변이 | 변경 | 기대 |
|---|---|---|
| mut01_no_overlap | 오버랩 제거 (gamer 버그와 동일) | KILL |
| mut02_s2_reentry | "11101" 깨짐 | KILL |
| mut03_pattern_1100 | 1100 검출로 극성 반전 | KILL |
| mut04_s1_wrong_zero | S1에서 din=0 시 잘못된 전이 | KILL |
| mut05_registered_hit | hit 1사이클 레지스터 지연 (타이밍 공격) | KILL |
| mut06_equiv_encoding | **동등 돌연변이** — S2/S3 인코딩 스왑, 행동 동일 | SURVIVE |
| mut07_reset_to_s1 | 리셋 상태 변경 | KILL |
| mut08_false_start | S0에서 din=0에도 전진 | KILL |

## 결과

- 행동 변경 돌연변이 **7/7 KILL → mutation score 1.0**
- 동등 돌연변이(mut06)는 예상대로 생존 — 감사 캘리브레이션 정상
- 특히 mut05(결과 1사이클 지연)도 격리됨 → 히든 채점기가 패턴 *개수*가 아니라
  **사이클 정확 타이밍**을 채점한다는 증거

## 배운 것 / 고친 것

- mutation score는 **동등 돌연변이를 제외하고** 계산해야 한다(포함하면 87.5%로
  오독). 이 캘리브레이션 절차 자체가 채점기 품질 메타데이터.
- "히든 테스트가 있다"와 "히든 테스트가 강하다"는 다르다. 환경의 채점기는
  돌연변이 감사 결과를 동봉해야 신뢰 등급을 매길 수 있다.
