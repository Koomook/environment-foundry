# Iteration 1 — 순차 블록으로의 계약 전이

- 날짜: 2026-07-29 · 상태: `OBSERVED`
- 산출물: `knowledge/lab/experiments/ai-chip-foundry-v2/` (실행: `uv run python .../run_v2.py`)
- 원시 결과: `results/iteration-1.json`

## 가설

v1이 조합 블록(ALU, 포화가산기)에서 검증한 환경 계약(관측 경계 → 타입화된 행동 →
실제 툴 전이 → 공개/히든 채점 → 리셋/리플레이)이 **내부 상태를 가진 순차 블록**에도
그대로 전이된다.

## 만든 것

- 과제: 오버랩 허용 "1101" 시퀀스 검출기 (Mealy hit)
- 후보 3개: `seq_gold`(정답, 오버랩 처리), `seq_gamer`(공개 테스트만 통과하도록
  오버랩 미처리), `seq_alt_onehot`(정답, 다른 인코딩 스타일)
- 공개 채점: 비오버랩 시퀀스 3개 (gamer도 통과하도록 구성)
- 히든 채점: **16,384개 시퀀스 × 14비트 전수**, 사이클 정확 독립 골든 모델
  (4비트 윈도우 == 1101) 대조

## 결과

| 후보 | 공개 | 히든(229,376 사이클 체크) |
|---|---|---|
| seq_gold | 통과 | **통과** |
| seq_alt_onehot | 통과 | **통과** |
| seq_gamer | 통과 | **실패** (오버랩 지점에서 불일치, 첫 실패 seq=91 bit=6) |

## 배운 것 / 고친 것

- 순차 블록의 히든 채점은 "입력 전수"가 아니라 **"시퀀스 전수 + 리셋 시맨틱스"**다.
  리셋 후 윈도우 초기화가 환경 계약의 일부가 됨.
- visible 게이밍은 조합/순차 무관하게 동일하게 작동하고, 동일한 방어(히든 행동
  게이트)가 잡아낸다 — v1의 결론이 블록 패밀리를 넘어 전이됨.

## 다음 가설 (→ iter-2)

히든 채점기의 판정을 신뢰하기 전에 **채점기 자체를 감사**해야 한다:
gold의 행동 변경 돌연변이를 주입해 100% 격리(kill)되는지 검증.
