# Knowledge operating rules

Use the relevant OKF slice first, then verify in the canonical wiki and cited source. Research is divergent, wiki is canonical, OKF is a reading layer, workstreams coordinate execution, and lab artifacts are inspectable evidence.

New knowledge follows this route:

```text
source receipt → research/candidate → workstream handoff
→ claim-level promotion review → typed wiki + index + log
→ optional OKF mission-spine update
```

Never promote a whole transcript, report, brief, or session. Promote atomic claims only. Private company/person payload has no Git raw fallback.
